# Linear Regression from Scratch 📈

This repository contains a professional implementation of the **Linear Regression** algorithm using only **NumPy**. It's part of my journey to master Machine Learning fundamentals at **Hanoi University of Science and Technology (HUST)**.

## 📝 About the Project
Instead of using high-level libraries like `scikit-learn`, I built this model from the ground up to deeply understand:
- **Matrix Operations:** Handling data with NumPy.
- **Loss Function:** Implementing Mean Squared Error (MSE).
- **Optimization:** Using **Gradient Descent** to minimize the cost function.

## 🏗️ Project Structure
- `train_model.py`: The core logic for training the model and updating weights.
- `main.py`: Script to run the training process and visualize results.
- `inference.py`: Load the saved model (`.pkl`) to make predictions on new data.
- `trained_linear_model.pkl`: The "brain" of the model after training.
